# Mundo 3D Festas — Landing pages

Páginas estáticas publicadas na Vercel em `lp.mundo3dfestas.com.br`.
Cada pasta vira um caminho: `pasta/index.html` → `lp.mundo3dfestas.com.br/pasta`.

| Pasta | URL |
|---|---|
| `imersao-registro-v1/` | lp.mundo3dfestas.com.br/imersao-registro-v1 |
| `imersao-registro-v2/` | lp.mundo3dfestas.com.br/imersao-registro-v2 |
| `imersao-registro-v3/` | lp.mundo3dfestas.com.br/imersao-registro-v3 |
| `imersao-registro-org/` | lp.mundo3dfestas.com.br/imersao-registro-org |
| `imersao-obrigado/` | lp.mundo3dfestas.com.br/imersao-obrigado |

Para criar uma nova página: nova pasta com um `index.html` dentro.
Arquivos compartilhados (imagens, CSS) podem ficar em `assets/`.
